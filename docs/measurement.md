# 测量、筛选与逐段诊断

## 先建立全部节点目录

记录订阅别名、节点别名、倍率、用途、测量时间、结论与淘汰原因。实际服务器参数、出口 IP 和原始节点名称放在本机文件。不要根据国家名推断入口独立；不同名称可能使用同一入口或相同出口。

全量扫描建议使用隔离的测试内核与独立代理端口。一次只测试一个节点，使用明确的叶节点选择，避免测试到自动组选择的另一条线路。扫描先做轻量请求，不对每个节点下载大文件。

1. 去除订阅中的额度提示记录，按连接参数识别重复别名。
2. 每组独立参数至少观察三次出口与轻量业务响应；失败和出口变化都保留。
3. 在支持的地区核验 ChatGPT、Claude、Gemini 等对应服务，分别确认 HEAD 判活与 GET 业务请求。
4. 使用 [Net.Coffee](https://ip.net.coffee/) 的 IP 查询、GPT / Claude 检测、DNS、WebRTC 等页面记录当时的评分与标记。评分请求必须对应实际出口；结果不是“独享 IP”或永不触发风控的保证。
5. 自动 AI 池优先低倍率、出口稳定且服务合格的候选；普通互动池看业务稳定性；下载池看容量、带宽和成本。
6. 同入口故障域保留不同入口的候选，同地区备用保留多个节点；高倍率、样本不足或不适合某服务的节点放手动目录。

公开测量工具提供当前路由的复用与单连接测速，没有全量节点扫描器或第三方评分 API 抓取。`qualified` 是使用者完成上述测量后填写的验收结论；可选的[后台程序](policy-monitoring.md)依据现有测量与运行健康记录监测，不会自动生成账号业务证据。

## 复用连接延迟

运行 `python tools/measure.py --kind latency --rounds 3`。每个站点每轮在一个 curl 进程中顺序发出 11 个 HTTP/1.1 请求。

- 丢弃第一个请求的建连与握手时间。
- 第一个请求必须建连一次；后面十个请求必须 `num_connects=0`，且全部状态 200。
- 计算后十个请求总耗时的中位数，然后取三轮中位数。
- 重连、错误状态、curl 非零退出或缺失样本会使整轮无效，失败记录保存，进程返回非零状态。

这个指标是 **HTTPS 请求完成时间**，包括代理转发、服务处理和小响应传输。它不是裸 TCP RTT，也不是 Ping。三个业务目标的结果分别报告，不能拿一个轻量 204 地址代替所有业务延迟。

## 单连接带宽

运行 `python tools/measure.py --kind bandwidth --rounds 3`。每轮下载 10,000,000 字节，HTTP/1.1、一个连接、状态 200、完整长度；不并发、不跟随重定向。带宽为实际字节数 × 8 ÷ 总耗时，单位 Mbps。

三轮共下载约 30 MB，倍率 5 的节点可能按约 150 MB 扣量，另有请求和协议开销。不要在正式高倍率节点上自动循环大文件测速。多连接测试可以单独比较，但不能宣称多个机场会叠加一个 TCP 连接的带宽。

## 晚高峰

在当地 20:00–23:00 另跑 `python tools/measure.py --rounds 1 --period evening`。保留时间和候选，不与白天三轮混成一个统计值。公开案例目前只有上午结果，晚高峰未验收。

## 业务与网页连通性

[Net.Coffee 网络连通](https://ip.net.coffee/link/) 页面要等待全部轮次结束。测试浏览器使用新建无登录上下文，不拦截或改写原页面请求。该页面的跨站 `no-cors` 请求不读取 HTTP 状态，404 也可能显示可达，适合作为补充网络观测。

业务端点要检查真实状态和语义：Registry 401 通常说明需要登录，某接口 405 说明方法不支持；不能把任意 403/404 都列为成功。GitHub API 403 要看是否匿名额度耗尽。Mihomo 的 HEAD 与人工 GET 必须分别记录。

登录成功、实际 AI 生成、长流、附件上传和账号风控是独立验收项目。匿名探测或评分 100 不替代这些项目，也不需要把账号令牌写进测试脚本。

## 按段诊断

| 环节 | 建议证据 | 可以判断的内容 |
|---|---|---|
| 电脑 → 家庭网关 | 网卡速率、网关轻量 ICMP、满载时对照 | 本地链路时延与排队；空闲低延迟不能证明满载正常 |
| 运营商接入 → 节点入口 | 同时段不同入口和订阅的对照 | 入口相关差异；仅国家名称不能证明不同物理入口 |
| 节点 → 海外服务 | 复用请求、单连接、同出口业务差异 | 业务响应与传输能力；不能凭总延迟准确拆出每段责任 |
| 出口 → AI / API | 地区、评分、实际方法和状态、登录会话 | 网关是否可访问、账号是否可用；两者分开 |
| 配置与客户端 | 生成和运行态比较、首匹配规则、隔离故障 | 错误分流、旧配置、检查状态污染与备用失效 |
| 计费 | 当前账单基线、倍率、采样与结算对照 | 是否因高倍率消耗；本机计量不等于供应商账单 |
